# CV site (sunJirapath.github.io)

Static GitHub Pages portfolio, no build step and no JS framework: `index.html` (content + small inline script for reveal, nav spy, mobile menu), `css/styles.css` (all styles; design rules in `DESIGN.md`), `cv.pdf`, `favicon.svg`, `og.png` (1200×630 link-preview image).
